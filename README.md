# Stock Screener

## Description
A powerful tool for screening and analyzing stocks based on various financial metrics and market indicators.

## Features
- Real-time stock data analysis
- Custom screening criteria
- Technical indicator calculations
- Financial ratio analysis
- Data visualization tools

## Installation
```bash
git clone https://github.com/yourusername/stock_screener
cd stock_screener
pip install -r requirements.txt
```

## Usage
```python
python stock_screener.py
```

## Configuration
1. Add your API keys in `config.py`
2. Customize screening parameters in `settings.json`

## Dependencies
- Python 3.7+
- pandas
- numpy
- yfinance
- matplotlib
